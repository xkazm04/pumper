### REJECTED — 6, with reasoning

**Outright (2):**
- **http-redirect-target-policy** — a public URL that `302`s to `169.254.169.254` escapes
  `/fetch-proxy`'s target policy (`Policy::limited`, `engine-http:255`). Real gap, but bound by
  the **r8 precedent**: "egress-hardening — no privilege gain on an unauthenticated local API."
  `[remote]` is default-off and a caller who can reach `/fetch-proxy` can already reach anything.
  Re-open if auth ships or `[remote]` becomes default-on.
- **plugin-params-redaction** — `plugin_params` land verbatim in the hash-addressed
  `rules_versions` table via `register_rules`. The r10 `transact-secret-redaction` precedent is
  real, but **that case had actual passwords in the flow**; here no shipped plugin takes a
  credential, and the job `params` row stores them regardless — so this would be a partial fix
  on a hypothetical. Banked; re-open the moment a plugin takes one.

**Deferred-banked (4):**
- **http-engine-observable** (feature · M) — the last engine with zero metrics. **Banked as
  http-engine's anchor**; deliberately sequenced *after* directions 1–3, which produce its two
  best series.
- **explicit `.no_proxy()`** — zero hits for `no_proxy`/`HTTP_PROXY` repo-wide, so a corporate
  box may egress all scraping through the system proxy while `[http] proxy` reads `None`. Rests
  on **unverified reqwest 0.12 semantics** — the scout flagged it SUSPECTED and the taste log's
  own rule ("brief rests on unverified external facts") says verify before slating.
- **plugin-search-identity** — `versions:"all"` collapses N revisions into one search doc
  (last-write-wins), plus ~20k sequential SQLite round-trips in the serial resolution loop.
  Interacts with `index_datasets`, which direction 5 deliberately does not touch. **Banked as
  plugin-runner's anchor.**
- **URL de-duplication** at the plugin door — confirmed, cheap, but pure scope-creep into
  direction 5. Banked, and named as an explicit non-goal in that direction's note so the builder
  doesn't drift into it.

**Folded as riders rather than slated** (each named in an acceptance criterion, not left to
